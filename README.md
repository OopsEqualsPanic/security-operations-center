# Self-Hosted Wazuh SIEM System Deployment


A self-hosted Security Information and Event Management (SIEM) platform deployed on a Linux server using Fedora IoT, Cockpit, Dockhand, Docker, and other technologies for easy configuration, version, and vulnerability management.

This project demonstrates the deployment, configuration, and operation of a security monitoring environment capable of collecting endpoint telemetry, detecting vulnerabilities, and analyzing security events.

## Reasoning
I wanted to actually apply my theoretical knowledge and current experience in information technology and cybersecurity to create something that I will keep using daily as I advance in my career.
Deploying a comprehensive stack for self-hosted technologies is also a great way to monitor, improve, and secure them. 


## Project Overview

The Wazuh platform is deployed inside a Docker environment hosted on a Fedora Atomic Linux server on a home network.

The deployment includes:
- Dockhand & Docker
- Wazuh Manager
- Wazuh Indexer
- Wazuh Dashboard
- Endpoint agents
- Vulnerability detection
- Security event & availability monitoring
- Firewall and network configuration
